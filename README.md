# CyberGrid-AI
This research presents RESIDUAL-DETECT, a sequential anomaly detection framework designed to identify stealthy false data injection (FDI) attacks targeting weather telemetry used in electricity demand forecasting. The framework leverages trusted electricity-demand measurements and cross-feature residual monitoring to detect inconsistencies between observed demand and potentially manipulated weather inputs. Evaluated across 384 attack scenarios, RESIDUAL-DETECT successfully identified 31 of 32 persistent attacks involving a 4°C temperature manipulation, demonstrating the effectiveness of cross-feature residual monitoring while highlighting its operational limitations and the challenges of detecting stealthy cyber-physical attacks in smart-grid forecasting systems.
